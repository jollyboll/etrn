Что такое ЭТрН?

Электронная транспортная накладная (ЭТрН) — это юридически значимый электронный документ, который заменил бумажную транспортную накладную (ТОРГ-12) при перевозке грузов.

С 2022 года все участники перевозочного процесса (грузоотправитель, перевозчик, грузополучатель) обязаны обмениваться транспортными накладными в электронном виде через операторов ЭДО.

Правовое основание: Приказ ФНС России от 21.11.2022 № ЕД-7-26/1119@, формат 5.03.

ЭТрН позволяет:

  • ✅ Ускорить документооборот в 5-10 раз
  • ✅ Исключить потерю документов
  • ✅ Автоматически проверять данные
  • ✅ Снизить затраты на бумагу и курьерские услуги
  • ✅ Получить юридическую силу через КЭП

Зачем нужен XML файл?

XML (eXtensible Markup Language) — это универсальный формат обмена данными, который используется операторами ЭДО для передачи транспортных накладных.

Наш сервис генерирует XML файл титула T1, который содержит все необходимые данные:

  • 📦 Информацию о грузоотправителе и грузополучателе
  • 🚛 Данные о перевозчике, транспортном средстве и водителе
  • ⛽ Сведения о продукте: масса, объём, плотность, температура, код ТН ВЭД
  • 📄 Номер и дату транспортной накладной

Важно: Сгенерированный XML файл вы загружаете в личный кабинет вашего оператора ЭДО, подписываете КЭП и отправляете контрагенту. Это полноценный юридически значимый документ.

Титулы ЭТрН

Электронная транспортная накладная состоит из нескольких титулов (разделов), каждый из которых заполняется определённым участником:

T1

Грузоотправитель

Заполняется грузоотправителем. Содержит информацию о сторонах перевозки, транспортном средстве, водителе, грузе (наименование, вес, объём, плотность, температура, код ТН ВЭД).

Формирует наш сервис
T2

Перевозчик

Заполняется перевозчиком. Подтверждает факт принятия груза к перевозке, указывает фактические даты и время.

T3

Грузополучатель

Заполняется грузополучателем. Подтверждает факт получения груза, указывает фактическое количество и состояние груза.

Форматы XML для ЭДО

Наш сервис поддерживает 4 основных формата XML, которые используются в России для обмена ЭТрН:

СБИС (Тензор)

Формат СБИС — один из самых распространённых в России. Используется в экосистеме СБИС (Тензор).

<ON_TRNACLGROT xmlns="http://www.nalog.ru/...">

Контур

Формат Контур используется в системе Контур.Диадок — популярном операторе ЭДО.

<Waybill xmlns="http://kontur.ru/edo/ttn">

Такском

Формат Такском — стандарт оператора ЭДО Такском.

<TTN xmlns="http://takskom.ru/edo/ttn/1.0">

Тензор

Альтернативный формат от компании Тензор.

<Document xmlns="http://tensor.ru/edo/ttn">

Как выбрать формат? Узнайте у вашего оператора ЭДО, какой формат он поддерживает, и выберите соответствующий в настройках генерации.

Интеграция с ЭДО (как происходит обмен)

Процесс обмена ЭТрН через оператора ЭДО выглядит следующим образом:

1
Создание XML — вы заполняете форму в нашем сервисе и получаете XML файл титула T1.
2
Загрузка в ЭДО — вы загружаете XML файл в личный кабинет вашего оператора ЭДО (СБИС, Контур, Такском и др.).
3
Отправка перевозчику — оператор ЭДО отправляет документ перевозчику через его оператора.
4
Подписание — перевозчик подписывает титул T2 своей КЭП, грузополучатель — титул T3.
5
Статус — все участники видят статус подписания документа.

Взаимодействие операторов: Операторы ЭДО связаны между собой роумингом, поэтому документ может быть отправлен от СБИС в Контур и обратно.

Как загрузить XML в ЭДО

СБИС / Тензор

  • Войдите в личный кабинет СБИС
  • Перейдите в раздел «ЭДО» → «Отправить документ»
  • Выберите тип документа «Транспортная накладная»
  • Загрузите XML файл
  • Выберите контрагента-перевозчика и отправьте

Контур.Диадок

  • Войдите в Диадок
  • Нажмите «Создать документ» → «Транспортная накладная»
  • Загрузите XML файл или скопируйте содержимое
  • Подпишите КЭП и отправьте контрагенту

Такском

  • Войдите в Такском-ЭДО
  • Выберите «Создать документ» → «Загрузить из файла»
  • Выберите XML файл и укажите тип документа
  • Отправьте получателю

Внимание: XML файл не подписан КЭП. После загрузки в ЭДО обязательно подпишите документ своей квалифицированной электронной подписью (КЭП). Без подписи документ не имеет юридической силы.

База данных контрагентов

Наш сервис включает удобную локальную базу данных для хранения информации о ваших контрагентах:

  • Грузоотправители — ИНН, КПП, наименование, адрес, телефон
  • Грузополучатели — ИНН, КПП, наименование, адрес
  • Перевозчики — ИНН, КПП, наименование, вид транспорта
  • Водители — ФИО, номер удостоверения
  • Подписанты — ФИО, должность
  • Транспортные средства — регистрационный номер, национальность
  • Продукты — наименование, код ТН ВЭД, плотность по умолчанию

Все данные хранятся локально в вашем браузере (IndexedDB). Вы можете экспортировать их в JSON файл для резервного копирования или переноса на другой компьютер.

Частые вопросы (FAQ)

Нужна ли КЭП для работы с вашим сервисом?

Нет, сам сервис не требует КЭП. Вы генерируете XML, а КЭП нужна для подписания документа в системе вашего оператора ЭДО.

Какие данные нужно заполнить для отгрузки?

Минимально необходимые: грузоотправитель (ИНН, название), грузополучатель (ИНН, название), перевозчик (ИНН, название), масса груза. Для продуктов с объёмом автоматически рассчитывается из массы и плотности.

Можно ли использовать сервис бесплатно?

Да, в бесплатной версии доступно до 5 записей в каждой категории. Для неограниченного количества — тариф PRO (250 ₽/мес или 1000 ₽/6 мес).

Где хранятся мои данные?

Все данные о контрагентах, ТС, водителях хранятся локально в вашем браузере (IndexedDB). Мы не передаём их на сервер.

Поддерживаются ли другие форматы XML?

На текущий момент поддерживаются 4 основных формата. При необходимости добавить новый формат — напишите нам на support@etrn.online.
