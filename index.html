О проекте

НефтеТрейд — специализированный онлайн-сервис для формирования XML документов транспортной накладной (титул Т1) для системы ЭТрН.

Сервис полностью соответствует требованиям Приказа ФНС России и поддерживает актуальную версию формата 5.03.
